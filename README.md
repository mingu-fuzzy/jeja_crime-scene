# 크라임씬 정답 판정 웹

정답과 응답 가능 횟수를 설정한 뒤, 참가자가 답을 입력해 정답 여부를 확인하는 정적 웹앱입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 사용할 수 있습니다. 서버나 별도 설치가 필요하지 않습니다.

## GitHub Pages 배포

1. 이 폴더의 파일을 GitHub 저장소에 올립니다.
2. 저장소의 **Settings → Pages**에서 배포 소스를 설정합니다.
3. 브랜치 배포를 선택하고 `/(root)`를 지정하면 사이트가 공개됩니다.

## 동작 방식

- 응답 가능 횟수는 1~99회로 설정할 수 있습니다.
- 답을 맞히거나 횟수를 모두 쓰면 결과가 표시됩니다.
- 정답과 진행 상태는 브라우저 메모리에만 있으며 새로고침하면 초기화됩니다.
- 백엔드 없는 정적 페이지이므로 보안이 필요한 비밀 정답용으로는 적합하지 않습니다. 사이트 파일을 볼 수 있는 사람은 코드에서 판정 방식을 확인할 수 있습니다.
